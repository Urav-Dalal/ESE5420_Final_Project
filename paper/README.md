# NeurIPS-style early draft

## Build

From this `paper/` directory:

```bash
pdflatex draft.tex
pdflatex draft.tex
```

Or upload `draft.tex`, `neurips_2024.sty`, and `figures/` to Overleaf and compile with pdfLaTeX.

Figures are copied from `../results/fig_cost_ap.png` and `../results/fig_calibration.png`.

## Content source

Numbers in the draft come from `../results/draft_results.json` and `../results/table_test_metrics.csv` produced by `../experiments_draft.py`.
